## 🌟 What is Stellar?
[Stellar](https://stellar.org/) is an open-source blockchain network optimized for payments and asset issuance. It was created to connect the world's financial infrastructure, allowing for fast transactions (under 5 seconds) with extremely low fees (fractions of a cent).

## 🎮 The Stellar Quest Journey
*"Launch Your Blockchain Education. Learn the Stellar blockchain, collect unique NFTs."*

[Stellar Quest](https://quest.stellar.org/) is an official gamified platform where you complete increasingly difficult challenges while learning to use Stellar's APIs and SDKs. Upon completing quests, you earn rewards and unique NFTs (badges) that can be displayed on your profile.

**About this Repository:** This project is a JavaScript implementation of the Stellar Quest challenges. It serves as an educational resource and practical guide to help you understand how operations work under the hood using real code.

## 🎒 Before You Begin (Basic Concepts)

Before running the code, here are two essential concepts in the blockchain world:
- **Public Key:** Starts with the letter **`G`**. Think of it as your bank account number. You can (and should) share it to receive funds.
- **Secret Key:** Starts with the letter **`S`**. This is your password! **NEVER** share this key with anyone and never put it in public repositories.

> [!CAUTION]
> **Security Warning:** Never commit your real *Secret Keys* to version control!

## 🛠️ Guide: How to use Albedo Wallet
To collect your unique NFT badges and rewards on the official [Stellar Quest](https://quest.stellar.org/) website, you don't need a wallet to start, but you will need one to **store your NFTs**. The recommended wallet is **Albedo**.

1. Go to [albedo.link](https://albedo.link/).
2. Click on **"Create a new account"**.
3. Follow the on-screen instructions to save your 24-word recovery phrase in a **highly secure place** (preferably written down on paper).
4. Create a strong password.
5. On the Stellar Quest website, connect using Albedo. Once you run the challenges from this repository and understand how the network works, you can apply this knowledge on the official site and receive your Badges directly into your Albedo account!

## 🚀 Quick Start

### Prerequisites
- **Node.js** (v20+ recommended) - The environment that runs our JavaScript code.
- **npm** (comes with Node.js) - The package manager to download Stellar tools.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/josiasdev/stellar-quest
cd stellar-quest
```

2. Install dependencies:
```bash
npm install
```

3. Run an example from Level 1:
```bash
node "src/level-1/1 - createAccount/createAccount.js"
```

**What should you expect to see in the terminal?**
When you run the command above, you will see output similar to this:
```
Account created successfully!
Public Key: G...
Secret Key: S...
```

### 🔍 Closing the Loop: See the magic happen!
Everything we do here runs on the **Testnet** (a test network using fake money). 
Copy the `Public Key` (starting with `G`) generated by your terminal and paste it into the **[Stellar Testnet Explorer](https://stellar.expert/explorer/testnet)**. You will see that your account was actually created on the blockchain!

## 📚 Learning Path

### Level 1: Fundamentals
- **[1 - createAccount](src/level-1/1%20-%20createAccount/README.md)** - Learn how to create new Stellar accounts
- **[2 - payments](src/level-1/2%20-%20payments/README.md)** - Send native XLM payments between accounts
- **[3 - change_trust](src/level-1/3-%20change_trust/README.md)** - Establish trust lines for custom assets
- **[4 - manage_offers](src/level-1/4-%20manage_offers/README.md)** - Create and manage trading offers
- **[5 - path_payments](src/level-1/5%20-%20path_payments/README.md)** - Execute path payments for asset conversion

### Level 2: Advanced Operations
- **[1 - account_merge](src/level-2/1%20-%20account_merge/README.md)** - Merge accounts and transfer native XLM balance
- **[2 - manage_data](src/level-2/2%20-%20manage_data/README.md)** - Store and retrieve key/value data entries on accounts
- **[3 - set_options_home_domain](src/level-2/3%20-%20set_options_home_domain/README.md)** - Link Stellar accounts to web domains (`stellar.toml`)
- **[4 - set_options_weights_thresholds_signers](src/level-2/4%20-%20set_options_weights_thresholds_signers/README.md)** - Configure multisig weights, operation thresholds, and signers
- **[5 - set_flags](src/level-2/5%20-%20set_flags/README.md)** - Set account flags (`authRequired`/`authRevocable`) and manage trustlines
